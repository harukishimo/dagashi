# 在庫管理

管理画面の「商品マスタ・在庫管理」で現在庫を入力します。新規商品は0個、既存の在庫未設定商品は従来どおり販売可能です。入荷・棚卸し時は実際の個数へ変更してください。空欄は在庫管理を解除します。「最新の在庫を確認」で一覧を更新できます。

在庫0個以下、または手動で「売切」にした商品は子ども画面でグレーアウトし、「売り切れ」と表示します。自動売切は入荷後に販売再開します。手動の「売切」は「販売中」への変更が必要です。

## Spreadsheet

最初の在庫保存でproductsのL1にstock_totalを追加します。A〜K列と既存のschema_version=2は変更しません。L列に別用途の見出しがある場合は保存を拒否します。実Spreadsheetへの事前の移行作業は不要です。

L列は現在庫ではなく計算用基準数（入力した現在庫＋その時点の消費数）です。直接書き換えず管理画面を使ってください。現在庫は基準数から取消されていない売上明細と完了済み特典交換を引いて算出します。同一明細IDは一度だけ計上します。売上取消は在庫を戻します。未完了売上の書込済み明細も安全側に予約在庫として計上します。応答不明取引を放置せず管理者が確認してください。

## 運用制約

会計・特典交換・棚卸しは一台ずつ順番に行ってください。棚卸し中に会計を行うと基準数と実数に差が出る可能性があります。Google Sheetsはトランザクションや条件付き更新がないため、Vercelの複数インスタンス間で厳密な在庫予約は保証できません。同時会計を行う複数レジ運用には、共有の排他処理またはトランザクション対応の保存先が必要です。負の在庫は管理画面にそのまま表示し、子ども画面では売り切れとして扱います。

既存の読取上限（商品999行、売上・明細等の固定範囲）は継承します。上限に近づく前に範囲拡張が必要です。過去の売上明細・特典交換の行を削除すると在庫計算が変わるため削除しないでください。
