# 購入後の10秒チャレンジ設定

管理画面 `/admin/settings` の「購入後の10秒チャレンジ」でオン・オフを変更します。保存には管理者セッションと同一オリジンのリクエストが必要です。

- 保存先: `settings` シートの `challenge_enabled`（文字列 `true` / `false`）、更新日時。
- 未設定の読み取りはオンです。変更前に `settings` に `challenge_enabled | true | 更新日時（ISO形式）` の行を1つだけ用意してください。未設定時の書き込みは競合による重複行を防ぐため拒否します。
- オフで作成する売上は `experienceStatus=skipped`、購入スタンプ1個となります。
- 売上保存完了後、子供画面はかご・リクエストIDを消去して `/` に戻ります。保存失敗や保存中は戻らず、同じリクエストで復旧します。
- 設定変更前に会計済みの取引は変更しません。再送時も保存済み取引の状態に従います。
- 成功時間、タイムアウト、店舗受付などの既存設定をこのAPIから書き換えることはできません。
- 操作は `audit_logs` の `setting.update` として記録します。保存失敗時は再読込し、現設定を確認してください（設定保存後の監査ログエラーもありえます）。
